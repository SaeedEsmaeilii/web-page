# استودیو طراحی وب‌سایت آرتا (Arta Studio Web Builder)

استودیو و صفحه‌ساز مدرن تحت وب بر پایه **GrapesJS Studio SDK**، یکپارچه‌شده با دیزاین سیستم **Ant Design (v5)** و بومی‌سازی کامل فارسی (راست‌به‌چپ RTL).

---

## قابلیت‌های کلیدی

- 🎨 **دیزاین سیستم Ant Design v5**: تمامی فرم‌ها، مودال‌ها، دکمه‌ها و ابزارها مطابق استانداردهای طراحی Ant Design پیاده‌سازی شده‌اند.
- 🇮🇷 **پشتیبانی کامل از زبان فارسی و RTL**: جهت راست‌به‌چپ، فونت استاندارد وزیرمتن (Vazirmatn) و ترجمه کامل محیط کاربری استودیو.
- 📥 **موتور هوشمند درون‌ریزی کد (Import Code)**:
  - تفکیک و اجرای ۱۰۰٪ تضمین‌شده استایل‌های CSS سفارشی.
  - پشتیبانی خودکار از کلاس‌های **Tailwind CSS** و آیکون‌های **FontAwesome**.
  - امکان درون‌ریزی مستقیم کد یا آپلود فایل‌های `.html`.
- 📤 **خروجی کد و تنظیمات صفحه (Export & SEO)**:
  - مشاهده و کپی کدهای HTML و CSS تفکیک‌شده صفحه.
  - تنظیم عنوان صفحه، توضیحات سئو و کلمات کلیدی.
- 📱 **واکنش‌گرایی کامل**: امکان سوییچ آنی بین نماهای دسکتاپ، تبلت و موبایل.

---

## راه‌اندازی و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه
npm run dev

# بیلد نهایی پروژه برای پروداکشن
npm run build
```
